# Evaluation Splits

The 80-question suite is reported in two layers:

- `eval/cases-baseline-60.jsonl`: ordinary business questions used as the primary robustness baseline.
- `eval/cases-advanced-20.jsonl`: deliberately difficult multi-step questions involving comparisons, nested aggregation, retention bands, inventory analysis, promotion ROI, and refund/after-sales joins.

The advanced split is not removed from the total score. Reports should show baseline, advanced, and total results separately so a single aggregate does not hide where the model succeeds or fails.

The split is deterministic and generated by `eval/split_cases.py`. It validates that the source has exactly 80 cases and that every advanced ID exists before writing either output file.

These suites measure real model behavior. The 80/80 Mock result remains a data, schema, and execution regression baseline only.
